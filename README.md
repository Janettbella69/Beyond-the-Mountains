# 出山 · Beyond the Mountains

> AI 驱动的互动叙事游戏（工作代号 `personal-legend`）：少年寻找天命的旅程——沿途相遇由 AI 实时生成、每局不同，被一条手写的主线母题牵引；结局不是选出来的，是你一路的选择"长"出来的。
>
> 灵感源自"寻找天命"的古老寓言传统（公有领域母题）。全新世界、全新主角、全新故事。

## 核心设计

**糖葫芦结构**：一根手写主线状态机（召唤 → 试炼 → 绿洲 → 至暗 → 顿悟 → 回归）串起 AI 实时生成的相遇。相遇只在主线节点的"格子"里生成、受母题约束，不放飞。

三层各司其职，缺一不可：

| 层 | 负责 | 实现 |
|---|---|---|
| dynamic | 活与无限 | AI 实时生成相遇，每局不同 |
| static | 弧光与不跑偏 | 手写主线状态机 + 4 支柱命题（恐惧/勇气、志业/热爱、爱/羁绊、信念/诱惑，主轴=天命） |
| eval | 质量与母题不崩 | 相遇 schema 结构化输出 + LLM-judge 母题/一致性校验，不合格重生成/回退 |

**镜子结局（题眼）**：终局由 AI 按玩家全程选择写就第二人称《你的天命之书》，首尾回到同一场景、照出蜕变——宝藏在自身。

**记忆层**是"故事性强"的技术来源：玩家的选择、遇过的人、埋下的伏笔，后文必须能呼应。

## 世界观与美术

东方架空，自创地名（云岫山 / 问津门 / 溪尾村），不用现实典籍专名。美术为光遇系氛围（借氛围、不抄设计，造型全原创）。视觉资产开发期预生成 + 人工定稿，运行时只实时生成文字。

## 技术架构

```
玩家输入 → Mastra 叙事引擎（TS：编排 / Agent / Memory / judge 校验）
              │  本地 HTTP / WS
              ▼
         UE5.8 表现层（VN 渲染壳：场景 / 对话框 / 选项 / 信念值）
```

- 叙事引擎：**Mastra**（TS 后端），导师为常驻记忆的活 NPC Agent（MVP 必带）。
- 表现层：**UE5.8** 只做渲染壳；UE 工程**不在本仓**（本地 `~/Documents/Unreal Projects/personallegend`）。
- 开发期工具链：Claude 经 MCP（端口 8002）驱动 UE 编辑器搭建场景与蓝图，脚本见 `tools/`。
